About this data

Sample data — edit it yourself. When a drop is announced, paste a new entry into the SNEAKERS array in the JS. Each shoe takes a name, brand, release date, retail price, resale estimate, prior-week price, and an optional image URL. That's the whole workflow — no API key, no backend.

Countdowns tick live (assumes 10 AM drop time), the bell opts you into browser notifications while this page is open, and "Buy on SNKRS" deep-links Nike/Jordan drops to nike.com/launch.

SneakerStock — built for the culture. Data shown is illustrative.
